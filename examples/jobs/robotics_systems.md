# Robotics Systems Engineer

## About the role

We build autonomous mobile robots for warehouse logistics. You will own the
software that connects sensors, planning, and actuators into a reliable robot
control stack — with strong simulation-first habits and production incident
discipline.

## What you'll do

- Design and implement robot control loops spanning perception → planning → actuation
- Build simulation environments that catch failure modes before hardware bring-up
- Own sensor fusion reliability (lidar, cameras, encoders) and calibration workflows
- Harden deployment of robot software across fleets with clear rollback paths
- Create observability for robot missions: stuck states, localization drift, estop events
- Partner with hardware and ops to diagnose field failures under time pressure

## Requirements

- Strong Python and C++ comfort for robotics / systems software
- Experience with ROS 2 or equivalent robot middleware
- Comfort with Linux, networking, and embedded-adjacent constraints
- Ability to debug closed-loop control failures using logs and simulation
- Bias toward measurable reliability: mission success rate, recovery time, false estops

## Nice to have

- Prior warehouse / AMR fleet experience
- Familiarity with motion planning, SLAM, or safety PLC boundaries
